YouTube Shorts Automated Generator & Uploader (Padiz Channel)

نحوه کارکرد پایپ‌لاین:
1. تولید ویدیو با گرافیک عمودی 1080x1920 استاندارد یوتیوب شورتس
2. فونت فارسی خوانا و زیبای وزیرمتن (Vazirmatn Bold) همراه با اصلاح Bidi و حروف‌چینی
3. گوینده هوش مصنوعی فارسی با کیفیت بالا (Edge-TTS)
4. رندر و ترکیب حرفه‌ای فریم‌ها و صدا با FFmpeg
5. اتصال مستقیم به YouTube Data API v3 و انتشار آنی یا برنامه‌ریزی‌شده

برای تست یا اجرای دستی:
python C:\youtube_pipeline\pipeline.py
